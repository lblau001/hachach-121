S-1 — the finale as a sequence

Decided 2026-09-03. This is the approved chronology for beat 5, exported from the v21 design canvas as a standalone page. Everything needed to build it is here; nothing links back to the canvas. The companion s1-SPEC.md beside this file carries the same numbers in prose.

The beat is a sequence, not a screen. The three earlier attempts were single static layouts and each read as chaotic because everything arrived at once. What follows is the order things arrive in, and what waits behind a tap.

The rule that shapes it: the tally is the peak and nothing else may land while it is counting; the player's flight is a second, separate beat; the coins get a moment of their own; the buttons arrive last and nothing follows them.

Why those three defer. They are the part players skip, and they were what made the old lower section unreadable — seven items competing in the bottom third. Keeping the first sentence visible means the beat still explains itself without a tap; the tap is for the people who want the rest.

5 · Type sizes, and the contrast finding

Contrast was never the problem. The old lower section was measured before any redesign and every element passed WCAG AA — explanation 8.25:1, guess line and links 7.08:1, chips 6.70:1, resolution 15.72:1, worst-in-set the בעד/נגד label at 5.32:1. Raising contrast would have changed nothing. The unreadability was size and density: 11–12.5px body copy with seven items competing. The fix is bigger type and fewer items on screen.

6 · The avatar token

Yellow keyline plus cyan glow — 0 0 0 3px #FFD60A, 0 0 0 4.6px rgba(0,0,0,.5), 0 0 18px 5px rgba(55,196,255,.72). It is the only object on the beat carrying both, so it can never be read as a verdict colour. The correctness rule is unchanged: lime #B6E521 and magenta #FF3BC0 code correctness only, never vote direction. The bar's בעד/נגד fills are the board's own #B6E521 / #FF7A6B and carry no correctness meaning.

7 · What this replaces

The 11×11 seat grid is rejected. The interleaved fill was a constraint set to avoid implying factional seating and it produced a checkerboard no one can read a majority from — honest, and illegible. What carries over is the V20-2 family: two numbers, left and right, a bar between, counting up. The new move is the avatar flight, which delivers the “121st MK” conceit through action rather than a dot in a grid.
